# Gastos motoca: como publicar no GitHub Pages

## Publicar (uma vez só)
1. Crie uma conta grátis em github.com e entre nela.
2. Clique em **New repository**. Nome: `gastos-motoca`. Deixe **Public** e clique em **Create repository**.
3. Na página do repositório, clique em **uploading an existing file** (ou Add file > Upload files).
4. Arraste **todos os arquivos desta pasta** (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) e clique em **Commit changes**.
5. Vá em **Settings > Pages**. Em **Source**, escolha **Deploy from a branch**, selecione a branch **main** e a pasta **/ (root)**, e clique em **Save**.
6. Espere 1 a 3 minutos. O link aparece nessa mesma página, no formato `https://SEU-USUARIO.github.io/gastos-motoca/`.

Os nomes dos botões podem variar um pouco, porque o GitHub muda a interface de vez em quando.

## Instalar no celular
- **Android (Chrome):** abra o link, toque nos três pontinhos e em **Instalar app** (ou Adicionar à tela inicial).
- **iPhone (Safari):** abra o link, toque em Compartilhar e em **Adicionar à Tela de Início**.

## Atualizar o app
Envie o novo `index.html` para o repositório (Add file > Upload files, com o mesmo nome) e confirme. Em alguns minutos todo mundo recebe a versão nova.

## Importante
- Os dados ficam só no aparelho de cada pessoa. Use **Meses > Exportar backup** para guardar uma cópia, e **Importar backup** para restaurar ou passar para outro celular.
- Quem desinstalar o app ou limpar os dados do navegador perde os lançamentos que não tiverem backup.
